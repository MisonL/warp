# update-tab-config

就地更新已有的 Warp 标签页配置。

## 必需上下文

- 使用 `tab-configs` 技能作为以下内容的权威来源：
  - 结构细节
  - 校验规则
  - 示例
  - 常见布局模式

## 工作流

1. 修改前先读取现有标签页配置文件。
2. 理解用户请求的编辑内容。
3. 如果关键细节缺失或有歧义，在编辑前使用 `ask_user_question` 工具。不要猜测布局变化、命令变化、参数或 `on_close` 行为。
4. 确认你编辑的是用户当前 Warp 构建或渠道对应的标签页配置，而不是假设固定基础目录；随后更新文件，并确保它仍符合 `tab-configs` 结构。
5. 除非请求本身要求重构，尽量保留用户已有结构和命名。
6. 简要说明改动内容。
