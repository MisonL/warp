# tab-configs

这是 Warp tab config TOML 文件的权威参考。

标准 Warp build 的 tab config 位于 `~/.warp/tab_configs/`。非 stable build，例如 Preview 或预发布 channel，会使用 channel 专属目录，例如 `~/.warp-<channel>/tab_configs/`。不要使用 `~/Library/Application Support/`，那不是正确位置。

要找到当前活跃数据目录，检查用户机器上已有的 `~/.warp*` 目录。每个 `.toml` 文件定义一个会出现在 `+` 菜单中的标签页布局。用户选择后，Warp 打开新标签页，按配置创建 pane layout 并运行命令。

本技能作为共享上下文：

- `create-tab-config` 创建新配置时应读取。
- `update-tab-config` 修改已有配置时应读取。
- 若本技能被直接用于创建或编辑任务，也按以下规则执行。

## 写入或编辑前

- 请求缺少关键信息时，使用 `ask_user_question`，不要猜。需要确认新建还是编辑、pane layout、目录、命令、哪个 pane 聚焦、是否需要参数。
- pane ID 使用 `"editor"`、`"server"`、`"top_left"` 这类描述性名称，不要用 `"pane1"`。
- 新配置文件名用 snake_case。
- 创建或定位配置时，使用当前 Warp build/channel 对应的 tab config 目录，不要硬编码单一 base 目录。
- 更新已有配置时先读取文件，并尽量保留用户结构。

## Schema 参考

### 顶层字段

- `name`，必填 string：显示在 `+` 菜单中的名称。
- `title`，可选 string：自定义 tab 标题，支持 `{{param}}` 模板变量。
- `color`，可选 string：tab 颜色，只能是 `"black"`、`"red"`、`"green"`、`"yellow"`、`"blue"`、`"magenta"`、`"cyan"`、`"white"`。

### Pane 列表

所有 pane 都定义在扁平的 `[[panes]]` table array 中。第一个 entry 是 root。每个 entry 要么是 split node，要么是 leaf node。

#### Leaf node 字段

- `id`，必填 string：唯一标识。
- `type`，必填 string：`"terminal"`、`"agent"` 或 `"cloud"`。
- `directory`，可选 string：初始工作目录，支持 `~` 展开，适用于 `terminal` 和 `agent`。
- `commands`，可选 string array：打开时按顺序运行的命令，适用于 `terminal` 和 `agent`。
- `is_focused`，可选 bool：最多一个 pane 可设为 `true`，作为初始焦点。
- `shell`，可选 string：该 pane 使用的 shell，例如 `"pwsh"`、`"zsh"`、`"bash"`、`"fish"`。仅适用于 `terminal` 和 `agent`。省略或 shell 未安装时使用用户默认 shell。

#### Split node 字段

- `id`，必填 string：节点唯一标识。
- `split`，必填 string：`"horizontal"` 表示 children 从左到右排列，`"vertical"` 表示从上到下排列。
- `children`，必填 string array：有序 child pane ID 列表，至少 2 个。顺序就是视觉顺序。

```toml
[[panes]]
id = "server"
type = "terminal"
directory = "~/code/backend"
commands = ["cargo watch -x run"]
```

### 尺寸

同一 split 下的所有 children 等分空间。没有 flex 或比例值。

### 参数

参数让用户在打开配置时通过 modal 填值。用 `[params.<name>]` table 声明。可在 `directory`、`commands`、`title` 中用 `{{name}}` 引用。

`{{autogenerated_branch_name}}` 是保留模板变量：若 tab config 引用它，Warp 每次打开时自动生成唯一 worktree branch name，而不是提示用户输入。

每个参数可包含：

- `type`，可选 string：`"text"` 默认、`"branch"` git branch picker、`"repo"` repo picker。
- `description`，可选 string：显示在填值 UI 中。
- `default`，可选 string：默认值。

```toml
[params.project_dir]
type = "repo"
description = "Project directory"

[params.branch]
type = "branch"
description = "Branch to check out"
```

### 校验规则

输出必须满足：

- `children` 中每个 ID 都引用已有 `[[panes]]` entry。
- pane tree 中不能有 cycle。
- leaf pane 不能有 `children` 或 `split`。
- leaf pane 必须有 `type`，取值为 `"terminal"`、`"agent"` 或 `"cloud"`。
- split pane 必须有 `split`，且 `children` 至少 2 个。
- 最多一个 pane 设置 `is_focused = true`。
- 所有 `id` 在文件内唯一。
- 第一个 `[[panes]]` entry 是 tree root。

## 示例

### 单 pane

```toml
name = "Dev Server"

[[panes]]
id = "main"
type = "terminal"
directory = "~/code/my-app"
commands = ["npm run dev"]
```

### 左右两 pane

```toml
name = "Editor + Server"
color = "green"

[[panes]]
id = "root"
split = "horizontal"
children = ["editor", "server"]

[[panes]]
id = "editor"
type = "terminal"
directory = "~/code/my-app"
commands = ["nvim ."]
is_focused = true

[[panes]]
id = "server"
type = "terminal"
directory = "~/code/my-app"
commands = ["npm run dev"]
```

### 2x2 网格

```toml
name = "Full Stack"

[[panes]]
id = "root"
split = "horizontal"
children = ["left_col", "right_col"]

[[panes]]
id = "left_col"
split = "vertical"
children = ["frontend", "backend"]

[[panes]]
id = "frontend"
type = "terminal"
directory = "~/code/frontend"
commands = ["npm run dev"]
is_focused = true

[[panes]]
id = "backend"
type = "terminal"
directory = "~/code/backend"
commands = ["cargo watch -x run"]

[[panes]]
id = "right_col"
split = "vertical"
children = ["tests", "logs"]

[[panes]]
id = "tests"
type = "terminal"
directory = "~/code/backend"
commands = []

[[panes]]
id = "logs"
type = "terminal"
directory = "~/code/backend"
commands = ["tail -f logs/dev.log"]
```

### 左侧主 pane，右侧上下堆叠

```toml
name = "Main + Side Stack"

[[panes]]
id = "root"
split = "horizontal"
children = ["main", "side_stack"]

[[panes]]
id = "main"
type = "terminal"
directory = "~/code/project"
commands = []
is_focused = true

[[panes]]
id = "side_stack"
split = "vertical"
children = ["top_right", "bottom_right"]

[[panes]]
id = "top_right"
type = "terminal"
directory = "~/code/project"
commands = []

[[panes]]
id = "bottom_right"
type = "terminal"
directory = "~/code/project"
commands = []
```

### 带参数

Warp 生成的 worktree config 默认使用 `~/.warp/worktrees/<repo-name>/<worktree-name>`。手写可复用配置时，在 shell runtime 用 `$(basename {{repo}})` 派生 repo name。

```toml
name = "New Worktree"
title = "{{branch_name}}"

[[panes]]
id = "main"
type = "terminal"
directory = "{{repo}}"
commands = [
  "git worktree add -b {{branch_name}} $HOME/.warp/worktrees/$(basename {{repo}})/{{branch_name}} {{base_branch}}",
  "cd $HOME/.warp/worktrees/$(basename {{repo}})/{{branch_name}}",
]

[params.repo]
type = "repo"
description = "Repository path"

[params.base_branch]
type = "branch"
description = "Base branch to branch from"

[params.branch_name]
type = "text"
description = "New branch name"
default = "my-feature"
```

## 常见模式

| 用户说法 | 生成内容 |
| --- | --- |
| "single pane" / "simple tab" | 一个 `[[panes]]` leaf entry |
| "split" / "side by side" / "two panes" | horizontal split，两个 terminal children |
| "top and bottom" / "stacked" | vertical split，两个 terminal children |
| "2x2" / "grid" / "four panes" | horizontal split，内含两个 vertical split，各有两个 terminal |
| "run X" / "auto-run X" | 把 `X` 放进 `commands` array |
| "with claude" / "running claude" | 对应 pane 使用 `commands = ["claude"]` |
| "three panes" 且无更多细节 | horizontal split，左侧一个 terminal，右侧 vertical split 两个 terminal |
