# create-tab-config

根据用户需求创建新的 Warp 标签页配置。

## 必需上下文

- 使用 `tab-configs` 技能作为以下内容的权威来源：
  - 结构细节
  - 校验规则
  - 示例
  - 常见布局模式

## 工作流

1. 理解用户想创建什么。
2. 如果缺少重要细节，在写入任何内容前使用 `ask_user_question` 工具澄清。不要猜测布局、命令、目录、参数或关闭时行为。
3. 生成符合 `tab-configs` 结构的有效 TOML。
4. 确定用户当前 Warp 构建对应的标签页配置目录。标准构建使用 `~/.warp/tab_configs/`；非稳定构建使用带渠道的变体，例如 `~/.warp-<channel>/tab_configs/`。运行 `ls -d ~/.warp*/` 列出可用 Warp 数据目录，并选择对应当前运行构建的目录。不确定时询问用户使用的是哪个构建。若 `tab_configs/` 子目录不存在，则创建它。文件名使用描述性 snake_case，并以 `.toml` 结尾。
5. 如果目标文件名可能与现有配置冲突，且不确定应覆盖还是创建新文件，使用 `ask_user_question` 工具确认。
6. 简要说明已创建的内容，包括布局、命令和参数。
